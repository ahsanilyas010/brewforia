# Product model

Source: `Backend/models/productModel.js`, `controllers/productController.js`, live `GET /api/product/list` (8 products on 2026-11-24).
The 52 demo products in `Frontend/.../assets.js` are leftovers from a clothing tutorial. They are **not** used by the live site and will not be migrated.

## Schema to Shopify

| Source field | Type | Shopify target | Notes |
|---|---|---|---|
| `_id` | Mongo ObjectId | Metafield `custom.source_id` (single line text) | Used only so reruns can match. Handle is the primary match key. |
| `name` | string | `title` | Handle generated by slugifying the name. |
| `description` | string | `descriptionHtml` | Plain text, wrap in `<p>`. |
| `price` | number | Not stored directly | Equals the lowest `sizePrices` value. Redundant. |
| `sizePrices` | `{ "<size>": number }` | Variant `price` | One variant per size. |
| `sizes` | string[] | Option `Size`, one value per entry, one variant each | All 8 live products have exactly one size (50g, 100g, 180g, 200g). |
| `image` | URL[] (Cloudinary) | Product media, same order | 1 to 4 images per product. Alt text is not stored in the source, so alt = product title (flagged). |
| `category` | string | `productType` **and** a collection | See categories below. Theme filters use product type. |
| `bestSeller` | boolean | Membership in collection `best-sellers` | Home "BEST SELLER" section reads that collection. |
| `date` | Date | Not migrated (Shopify sets `createdAt`) | "What's NEW" shows newest first. Import order is by this date ascending so newest are created last. |
| `__v` | number | Dropped | Mongoose internal. |

Status: all created as `DRAFT` (hard rule 7). Vendor, SKU, inventory and weight do not exist in the source. They are left blank and listed for Ahsan in the handover.
Inventory tracking: off by default, so a product can sell once activated. Flag in handover.

## Categories to collections

| Source category | Products today | Shopify collection (manual) | Handle |
|---|---|---|---|
| Coffee | 4 | Coffee | `coffee` |
| Hot Chocolate | 0 | Hot Chocolate | `hot-chocolate` |

Empty collections are still created so the filter list matches the source.
Source `/collection` ("OUR PRODUCTS", all products with category filters) maps to the built in `/collections/all` with tag-less storefront filters on Product type.

## Metafields

Only one needed: `custom.source_id` (above). No other source field lacks a Shopify home.

## Cart, order, user models

- `orderModel` (userId, items, amount, address, status, paymentMethod, payment, date) and `userModel` (name, email, password, cartData): replaced by Shopify orders and customers. Not migrated (hard rule: no customers or orders).
